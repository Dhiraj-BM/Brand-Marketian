How we behave

Four rules every pod runs by. If we break one, you should call it out.

  1. 01

    Own the number

    Reach, cost per lead, ROAS — one agreed metric per account, reviewed every week. If it is not moving, we change the plan, not the slide.

  2. 02

    Say it plainly

    No jargon in reports and no hiding behind impressions. You should be able to explain your own marketing to your partners or your board.

  3. 03

    Build the brand first

    A name, a look and a story before the ad spend. Most of what we run started as a brand we built from scratch — the campaigns work because the brand underneath them does.

  4. 04

    You own everything

    Ad accounts, pages, creatives and data sit in your name from day one. Month-to-month, no lock-in — we stay because the numbers do.
